# AI Finance Controller

A simple project that helps people understand where their money is going.

## What we are trying to do

Managing money can get confusing when there are lots of small expenses. The idea behind this project is to make that easier by putting income and expenses in one place and using AI to find useful patterns.

The project will help users:

- Keep track of income and expenses
- Understand their spending habits
- See where most of their money is going
- Get simple budgeting suggestions
- Find unusual or unexpected expenses
- Ask questions about their own financial data

## Current Status

 This project is currently under development.

We are building it step by step and testing the features as we go.

## Planned Features

- Personal finance dashboard
- Expense tracking
- Expense categories
- Spending analysis
- Budget suggestions
- AI-powered financial insights
- Simple charts and reports

## Goal

The goal is not to make finance complicated. We want the user to be able to open the app, understand their current situation quickly, and know what they can improve.

## Disclaimer
